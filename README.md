# 🍦 ICE E — Artisanal Cold Craft & Sweet Scoops

A high-performance, animation-rich interactive ice cream web application built with **React**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

---

## ✨ Features & Animations

- **Hero Experience**: Interactive 3D floating ice cream cone with dripping sauce physics, ambient drifting treats, live flavor switcher, and responsive spring animations.
- **Interactive "Gravity Cone" Laboratory**:
  - Drag or click to stack up to 4 scoops with spring physics & wobbles.
  - Choose between hand-crafted waffle cones, midnight charcoal cones, salted pretzel cones, or eco bowls.
  - Interactive toppings (Rainbow sprinkles, 24K gold dust, hot fudge drip, glacé cherry) with real-time price tallying and remove actions.
- **Signature Artisanal Flavors Showcase**:
  - Interactive flavor catalog with taste profile meters (Sweetness, Creaminess, Fruitiness, Crunch).
  - Modal drawer with botanical ingredient origins, nutritional info, and quick add-to-bag buttons.
- **Audio Feedback**: Playful haptic pops, chimes, and sparkle sounds powered by synthetic Web Audio API (zero external sound dependencies, includes a mute toggle).
- **Celebration Checkout**: Full slide-over bag drawer with free dry-ice delivery progress bar, quantity modifiers, and canvas-confetti checkout celebration.
- **Craft & Story Section**: Highlights -196°C micro flash freezing, Hokkaido cream, and compostable cones.
- **Infinite Testimonial Marquee**: Smooth CSS/Framer motion reviews ticker.

## 🚀 Quick Start

1. Open this folder in your terminal:
   ```bash
   cd "C:\Users\MIDHUN\.gemini\antigravity\scratch\ice-e"
   ```

2. Start the local development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🛠️ Tech Stack & Animation Dependencies

- **React 18** + **Vite** + **TypeScript**
- **Framer Motion** (`^11.x`): Physics springs, layout animations, entrance transitions, wobbles, and slide-overs.
- **Canvas Confetti**: Celebration bursts upon building dream cones and placing orders.
- **Tailwind CSS**: Custom candy pastels, waffle textures, and glassmorphic blur styles.
- **Lucide React**: Modern iconography.
- **Web Audio API**: Synthetic pop & chime effects for interactive feedback.
